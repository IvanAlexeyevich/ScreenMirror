# 0.2.1: ошибки ReplayKit

Изменено только представление ошибок: передаётся явный NSError с текстом
и этапом, чтобы iOS не заменяла причину общим Broadcast.MirrorError (1).
Это диагностическое исправление, не подтверждённое устранение сбоя трансляции.
Проверен синтаксис Swift и plist; сборка Xcode и отображение на iPhone не проверены.

Для уже установленной версии можно открыть Console на Mac, выбрать iPhone и
фильтровать subsystem org.example.ScreenMirror или процесс Broadcast.
Повторный запуск даст исходный log.error из SampleHandler даже без обновления.
